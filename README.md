# PS Cafe Manager — V6.4.1 EC5

**Cloud Execution Candidate / Local Review Only Until Approval**

هذه الحزمة مبنية على نسخة R4 التي تم اختبار واجهتها محليًا، وتضيف التجهيز السحابي الآمن لقاعدة Supabase المملوكة لصاحب النشاط.

## الوضع الحالي

- `V6.3.0` ما زالت النسخة المنشورة المستقرة ونقطة الرجوع.
- لا يتم رفع ملفات هذا الإصدار إلى GitHub الآن.
- لا يتم تشغيل SQL الآن حتى اكتمال الاختبار المحلي الإضافي وموافقة المالك.

## ما تغير بعد اختبار R4

- حماية قاعدة البيانات: الفاتورة الملغاة نهائية ولا يمكن إعادتها أو تعديلها بعد الإلغاء.
- حماية Owner: لا يمكن تعطيل أو تخفيض صلاحية آخر Owner فعال في النشاط.
- المصروفات: إلغاء موثّق داخل واجهة التطبيق، مع الاحتفاظ بالمصروف الملغى كسجل وعدم احتسابه في التقرير.
- تقرير اليوم: استخدام تاريخ النشاط بتوقيت مصر (`Africa/Cairo`) لتجنب خطأ ما بعد منتصف الليل.
- تثبيت صيغة الربط السحابي على `normalized_v2_controlled_corrections`.

## ملفات التنفيذ لاحقًا
